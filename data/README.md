# Inference references

antibacterial.fasta is the official challenge reference for exact duplicate exclusion and
Top-100 similarity compliance. training/training.fasta is the supplied AMP-Diffusion reference
of 19,670 sequences for length and embedding-distribution matching and novelty.
Both are unchanged supplied artifacts. See ../DATA_SOURCES.md and ../source_provenance.json.
Additional source database redistribution is deferred. Public access and a paper's license
are not treated as blanket permission to redistribute each underlying database.
